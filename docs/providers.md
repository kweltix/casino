# Подключение источников и моделей

Проверено 28 октября 2026 года. Выбор источников расширен пользователем: 2ГИС, Яндекс Карты и аналогичные каталоги допустимы.

## Реализованный способ

OpenAI Responses API с инструментом `web_search` ищет публичные сведения об автосервисах. Приложение не обращается напрямую к закрытым API каталогов и не обходит ограничения. Источниками могут быть индексируемые карточки 2ГИС/Яндекса, каталоги и сайты самих компаний. Покрытие источников и доступность отдельных страниц не гарантированы. Допустимость конкретного использования материалов и хранения должна учитываться перед коммерческим масштабированием; результаты поиска не предоставляют прав на чужие фотографии.

Отдельный запрос ищет собственный сайт по названию/адресу и до двух конкурентов. URL принимаются только если они присутствуют в источниках/цитированиях самого инструмента веб-поиска. Извлечённые сведения — машинный пересказ, не заверенная цитата; возможные ошибки проверяет пользователь. Статус «не найден» относится только к конкретной проверке. Для ручных данных сохраняется пометка о происхождении.

Текстовый анализ использует структурированный JSON и ссылки на переданные source ids. Картинка генерируется только по отдельному действию пользователя. Приложение не рассылает сообщения.

## Настройки

- `AI_PROVIDER_API_KEY`: ключ OpenAI, только сервер. В cloud environment добавляется в защищённых настройках как секрет для `api.openai.com`; не вводить в чат, Git или клиентский интерфейс.
- `AI_TEXT_MODEL`: по умолчанию `gpt-5-mini`, требуется поддержка Responses, web_search и структурированных ответов.
- `AI_IMAGE_MODEL`: по умолчанию `gpt-image-2.5-flare`. Нужен доступ аккаунта к Images API. Официальный актуальный OpenAPI помечает старый `gpt-image-1` как отключённый 23 октября 2026 года.
- `DATABASE_PATH`: `data/agent.sqlite`; `ARTIFACT_DIR`: `data/artifacts`.

Запросы уходят только на `https://api.openai.com/v1/responses` и `/v1/images/generations`. Worker запускается с Node `--use-env-proxy`, чтобы использовать сетевой прокси среды. Заданный ключ не означает проверенный доступ: ошибки прав, баланса, модели и сети отображаются в заданиях.

## Официальные ссылки и фактическая проверка

- [OpenAI OpenAPI](https://github.com/openai/openai-openapi/blob/master/openapi.yaml): получен через официальный raw.githubusercontent.com, проверены пути Responses/Images, web_search, web_search_call.action.sources, структурированные ответы и поля изображений.
- [Responses API](https://developers.openai.com/api/reference/resources/responses/): HTML-документация первоначально недоступна по сетевой политике; использован официальный OpenAPI.
- [Яндекс Search API](https://yandex.ru/maps-api/docs/geosearch-api/index.html) и [условия API](https://yandex.ru/legal/maps_api/): проверка вернула proxy 403. Прямой адаптер Яндекс API поэтому не реализован и не заявляется работающим.
- Прямой API 2ГИС не подключён; используется только доступный веб-поиск. Чужие отзывы и фотографии массово не копируются.

## Стоимость и ограничения

Точные тарифы и стоимость для аккаунта не проверены: стоимость показывается как «неизвестна», а не 0. Успешные текстовые запросы сохраняют количество токенов, изображения — доступный usage; стоимость проверяется в биллинге OpenAI. Повторные попытки и отменённые запросы могут тарифицироваться. До реального запуска нужны ключ, баланс и разрешённый сетевой доступ.

До 20 компаний на запуск, до 4 вызовов поиска в одном запросе, до 3 попыток одного задания. Поиск и анализ имеют таймаут 30 секунд, генерация 120 секунд. При квоте/отказе доступа автоматические повторы прекращаются. Отмена останавливает новые этапы и сохранение результата; уже отправленный запрос провайдера может завершиться и быть оплачен.

Сквозная проверка с реальными провайдерами пока не выполнена: ключ отсутствует. Тестовые ответы проверяют приложение, но не являются проверкой доступа к OpenAI или реальных компаний.
