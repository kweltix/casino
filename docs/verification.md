# Проверка первой версии

28 октября 2026 года. Реализована локальная версия веб-приложения и отдельного worker для исследования автосервисов Екатеринбурга.

## Подтверждено

- `npm_config_devdir=/workspace/.cache/node-gyp npm ci --cache /workspace/.npm-cache`: повторная установка успешна, 77 пакетов. Без devdir нативная сборка пытается писать в недоступный домашний каталог.
- `npm test`: 42 проверки прошли. Проверены SQLite, очередь, fencing/retry/cancel, провайдерные контракты, источники, ограничения HTTP, конфликты версий, сохранность пользовательских сообщений и конкурирующие соединения WAL.
- `npm run typecheck`: успешно.
- `npm run build`: production-сборка успешна.
- `npm run test:e2e`: 2 сценария прошли в системном Chromium. Проверены поиск и обработка через настоящий отдельный worker с синтетическими провайдерами, редактирование, сохранение, референс, отмена, повторная загрузка и мобильный экран.
- Отдельная production-проверка на порту 3002 с `data/smoke-agent.sqlite`: создание, изменение и чтение ручной компании успешны; настоящий worker корректно переводит задание в blocked при отсутствии ключа. Платных внешних запросов не было.
- Независимый read-only обзор gpt-6-astra выявил 3 Important, 0 Critical. Все три исправлены в одном проходе, с воспроизведением ошибок в тестах до исправления и зелёным полным набором после него. Повторного независимого обзора после исправлений не проводилось.

## Исправления после обзора

1. Все составные записи используют внешнюю immediate-транзакцию SQLite, исключающую описанный конфликт обновления WAL snapshot. Проверка использует два реальных соединения.
2. Для собственного сайта нужны конкретный цитируемый URL и совпадение названия с адресом или телефоном в пересказе этой страницы. Один hostname, посторонняя компания и карточка известного каталога не подтверждают сайт.
3. Отмеченное происхождение текста и статус обращения защищают пользовательские и проверенные сообщения от повторного анализа. Сгенерированные неподтверждённые черновики можно обновлять; сохранённые пользователем тексты остаются его работой.

## Не подтверждено

Реальные запросы к OpenAI, качество поиска компаний, актуальность сведений, совместимость моделей с конкретным аккаунтом и качество настоящих картинок: ключ `AI_PROVIDER_API_KEY` отсутствует. Тестовые ответы не заменяют эти проверки. После безопасного подключения ключа, разрешения сетевого доступа и перезапуска процессов нужно выполнить малый реальный запуск, проверить источники и картинку, затем запуск до 20 компаний.

Стоимость пока неизвестна: учитываются попытки и доступные токены, но точные расходы сверяются в биллинге провайдера. Остановка не гарантирует отмену тарификации уже отправленного запроса.

## Решения исполнителя и их последствия

- Использован существующий изолированный checkout на ветке work, без дополнительного worktree. Это соответствует согласованному проекту; дополнительной границы изоляции нет.
- Облачные вспомогательные скрипты навыка недоступны как исполняемые файлы; использованы локальный журнал и явные команды проверки. Поведение продукта не меняется.
- Queue принимает Store явно для общей транзакции и изолированных реальных баз в тестах. Пользовательского изменения нет.
- Прямой API Яндекса первоначально оставлен заблокированным из-за недоступной документации/условий и отсутствия ключей. Затем пользователь разрешил 2ГИС и аналоги, и выбран OpenAI web_search с публичными цитируемыми источниками. Прямые API каталогов не подключены; покрытие зависит от веб-поиска и ключа.
- Официальный актуальный OpenAPI помечает gpt-image-1 как отключённый 23 октября; выбран документированный gpt-image-2.5-flare. Доступ конкретного аккаунта ещё не проверен.
- Один catch-all маршрут API заменяет набор одинаковых файлов-обёрток. Все согласованные пути и проверки методов сохранены.
- Браузерные проверки используют отдельную .next-e2e и тестовую базу, чтобы не конфликтовать с рабочим сервером. Рабочие данные не очищаются.
- Непроверенные внешние интеграции остаются явным блокером. После подключения могут обнаружиться ограничения аккаунта/модели.
- Машинные пересказы, даже с проверенными ссылками и совпадениями, требуют человеческой проверки. Без неё фактическая ошибка может попасть в предложение.
- Публичная аутентификация и коммерческое масштабирование источников за пределами локальной версии. Нельзя открывать эту версию в Интернет без дополнительной работы.
- Визуальный результат проверен автором по снимкам и браузерным сценариям; независимый обзор был сосредоточен на коде. Другие размеры экранов могут потребовать доработок.

Отложенных Minor-замечаний независимого обзора нет.

## Конфигурация среды

В draft сохранены install_script и start_skill, требование секрета AI_PROVIDER_API_KEY для api.openai.com и сетевые домены api.openai.com, developers.openai.com, platform.openai.com, yandex.ru, yandex.com, search-maps.yandex.ru. Пресеты пакетных менеджеров сохранены. Указанное сохранение не применяет настройки, не задаёт значение ключа и не публикует snapshot. Для активации требуется проверить и сохранить настройки в интерфейсе среды, затем опубликовать среду. Секретные значения в репозиторий не добавлены.
