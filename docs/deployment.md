# Защищённый запуск и Render

## Локально

Из корня проекта выполните `npm run auth:setup`. Команда создаёт случайный пароль в приватном игнорируемом `data/admin-access.txt` и `APP_PASSWORD` в `.env.local` (режим файлов 0600). Пароль не выводится в журнал и не попадает в Git. Существующий пароль не заменяется. Не отправляйте эти файлы в чат или репозиторий.

После `npm run build` команда `npm run serve` запускает production-сервер и фоновый worker вместе. По умолчанию сервер слушает loopback, порт 3000; обе части останавливаются, если одна неожиданно завершится. Для разработки по-прежнему доступны `npm run dev` и отдельно `npm run worker`.

Локальный запуск в удалённой облачной среде не даёт публичной ссылки. Адрес localhost на вашем устройстве не ведёт в эту среду. Проверенные сервисы временных туннелей (trycloudflare, localtunnel, localhost.run) вернули сетевой proxy403; внешний доступ через них не подготовлен.

## Бесплатно на своём компьютере

- Windows: запустите `launch/local.bat` после установки и запуска Docker Desktop.
- Linux/macOS: выполните `bash launch/local.sh` при работающем Docker.

Оба скрипта создают приватный пароль, собирают проверенный Dockerfile и запускают web/worker с локальным портом 3000. Данные находятся в постоянном Docker volume `ai-agent-local-data`, пароль — в `data/admin-access.txt`. На вашем компьютере это не требует аккаунта хостинга. Этот адрес не становится публичным. Docker/Desktop должен быть доступен вашему пользователю; сборка требует Интернет. Не отправляйте приватные файлы доступа другим людям. Контейнер и его функции проверены в Linux; Windows batch-файл здесь не запускался.

## Бесплатная публичная ссылка

По просьбе пользователя прежний Blueprint удалён. Альтернатива — Cloudflare Workers Free + D1. [Официальная документация Workers](https://developers.cloudflare.com/workers/platform/pricing/) подтверждает бесплатный план с лимитами; бесплатный хостинг не означает бесплатные запросы OpenAI.

Существующий Node/SQLite-контейнер нельзя запустить в Workers напрямую: требуются перенос базы в D1, адаптация аутентификации и очереди, а также выполнение фоновых этапов в рамках лимитов. Эта адаптация ещё не реализована. Для публикации нужен аккаунт Cloudflare и разрешение на развёртывание, которых в этом чате нет. Не публикуйте токены доступа в чате.

Проверены и отклонены другие варианты: актуальная официальная документация Hugging Face требует платный план для создания Docker Spaces; документация Northflank требует платёжный метод даже для Sandbox. Сервисы временных туннелей недоступны из текущей среды. Пользователю не обещается бесплатная публикация через эти пути.

## Защита и эксплуатация

- Вход закрывает страницу и все data API, включая картинки. Только минимальный `/api/health` доступен без входа.
- Без корректного `APP_PASSWORD` сервер `serve` не запускается; при других способах запуска данные всё равно закрыты.
- Сессия — случайный 256-битный токен в HttpOnly SameSite=Strict cookie на 8 часов. Для HTTPS — Secure cookie с префиксом __Host-. В базе хранится хэш токена. Смена APP_PASSWORD и перезапуск отзывают прежние сессии; выход удаляет текущую сессию в базе.
- Пять попыток входа за 15 минут ограничиваются глобально и сохраняются в SQLite. Это защищает единый вход от перебора, но посторонний может временно исчерпать лимит входа. Уже открытые сессии продолжают работать.
- Docker-образ сначала готовит владельца каталога данных, затем сбрасывает root до UID/GID 1000 перед запуском приложения и worker. Не масштабируйте контейнер на несколько экземпляров с локальной SQLite.
- База, референсы и сессии находятся на временном `/app/data`. При локальном запуске через launch данные сохраняются в Docker volume. При ручном запуске без volume файловая система контейнера временная. Сохраняйте резервные копии.
- Автоматическая отправка сообщений бизнесам отсутствует.
