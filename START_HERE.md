# Запуск AI Agent на своём компьютере

Хостинг и аккаунт для размещения не нужны. Приложение работает только на вашем компьютере; компании и изображения сохраняются в локальном Docker volume.

1. Установите Docker Desktop с https://www.docker.com/products/docker-desktop/ и запустите его. Для личного использования доступен бесплатный вариант. Если Docker уже установлен и работает, этот шаг не нужен.
2. Полностью распакуйте архив в отдельную папку. Не запускайте файлы прямо из ZIP.
3. Windows: откройте `launch` и запустите `local.bat`. macOS/Linux: откройте терминал в распакованной папке и выполните `bash launch/local.sh`.
4. Дождитесь сборки и сообщения о готовности сервера. Первый запуск загружает зависимости и может занять несколько минут; нужен Интернет.
5. Откройте браузер на вашем компьютере и введите адрес `http://localhost:3000`. Это локальный адрес именно вашего компьютера, а не ссылка на облачную среду.
6. Пароль для входа находится в текстовом файле `data/admin-access.txt` внутри распакованной папки. Никому его не отправляйте.

Оставляйте окно запуска открытым, пока работаете с агентом. Для остановки нажмите Ctrl+C в нём; для следующего запуска используйте тот же скрипт. База хранится отдельно от контейнера, в volume `ai-agent-local-data`. Не удаляйте этот volume в Docker Desktop, если нужны сохранённые компании.

## Подключение AI

Хостинг не оплачивается. Запросы OpenAI оплачиваются отдельно в вашем аккаунте. Без ключа работают ручной ввод компаний и редактирование предложений.

Чтобы включить автоматический поиск, анализ и картинки, добавьте строку `AI_PROVIDER_API_KEY=ваш_ключ` в приватный `.env.local` рядом с package.json. Сохраните существующую строку APP_PASSWORD. Не отправляйте этот файл в чат или Git. Затем остановите приложение и запустите скрипт снова.

## Если запуск не удался

Сначала убедитесь, что Docker Desktop запущен. В Windows при необходимости запускайте local.bat через терминал, чтобы увидеть сообщение об ошибке. Проверка контейнера и Linux-команд выполнена; Windows batch-файл в этой среде не запускался. Если порт 3000 уже занят другой программой, остановите её или настройте другой локальный порт.
